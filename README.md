# StudyBuddy

StudyBuddy is a private offline-first HTML/CSS/JavaScript study planner.

## Run locally

Open `index.html` directly in a browser, or serve this folder with any static file server. No install, backend, or API key is required.

## Voice planning

Use a supported browser such as Chrome or Edge, allow microphone access, speak a request, and the browser transcript is parsed into local tasks. If browser speech service is unavailable, type the transcript instead. Tasks, habits, streaks, and preferences use `localStorage` only.
